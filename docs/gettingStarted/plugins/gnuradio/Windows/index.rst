On Windows
==========

Gnuradio-limesuiteng plugin on Windows can be installed as a conda package in a conda environment or can be built and manually installed alongside GNURadio application in conda environment. Currentlly plugin in Windows conda environment supports only GNURadio 3.10.9.2 (Python 3.12) version.
