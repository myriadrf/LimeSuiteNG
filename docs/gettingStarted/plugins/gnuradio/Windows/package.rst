Conda package
=============

Gnuradio-limesuiteng plugin for GNURadio 3.10.9.2 (Python 3.12.9) can also be downloaded as a conda package.


Prerequisites
-------------

Conda packages required to run the gnuradio plugin:

#. LimeSuiteNG
#. Python=3.12
#. Numpy=1.26.4
#. gnuradio=3.10.9.2

.. tip::
   You can check if packages are present by using ``conda list <package name>``.
   
Installing
----------

.. code-block:: bash

   conda activate <environment>
   conda install gnuradio-limesuiteng

Check out :ref:`gnuradio-limesuiteng-example-ref` section for plugin demonstration.

.. hint::
   Check out radioconda and conda environment set up process. See :ref:`radioconda-setup-ref`.
