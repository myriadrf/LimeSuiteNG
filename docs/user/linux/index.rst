Linux
=====

Lime Suite NG on Linux can be installed either using package manager or built from the source code. For first time radioconda users, it is recommended to check out the :doc:`radioconda` section for enivronment setup steps.

.. note:: It is advised to only use packages or only source build, to avoid potential libraries versions clashing.
