User Guide
==========

Here you can find details of how to install and use Lime Suite NG on different platforms. Topics covered include building from source and installing Lime Suite NG via packages, as well as using the provided command-line tools to configure your device, update firmware and gateware, and transmit or receive data to and from files. Details are also provided for plugins that enable using LimeSDR devices with popular SDR ecosystem software such as GNU Radio and applications that support the SoapySDR API.

.. note::
   The CLI tools provide a simple interface that can be used for basic device configuration, as well as testing and debugging. Most usage will be via applications that integrate with the library APIs directly or via plugins.
