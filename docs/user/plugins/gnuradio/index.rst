#########

Lime Suite NG provides `GNU Radio`_ source and sink blocks which are supported on Linux and Windows platforms. These blocks are available in the GNU Radio Companion (GRC) block library after installing the plugin. The blocks are designed to be used with supported devices and provide an interface for transmitting and receiving signals using GNU Radio.

.. _GNU Radio: https://www.gnuradio.org/
