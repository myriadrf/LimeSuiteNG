SoapySDR
#########

Lime Suite NG provides integration with `SoapySDR`_, the vendor- and platform-neutral SDR support library, enabling use with a wide range of SDR applications and frameworks that support the SoapySDR API.

The SoapySDR plugin for Lime Suite NG can be installed as an optional APT package on Linux. When installing Lime Suite NG from source, the plugin will be built by default if the SoapySDR development files are found.

.. _SoapySDR: https://github.com/pothosware/SoapySDR
